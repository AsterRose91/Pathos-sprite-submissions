# Pathos sprite submissions
Various sprites I contributed to the roguelike Pathos by callanh over the last couple years

https://github.com/callanh/pathos-official

I've decided to finally upload all 200+ of the sprites I've made so far to commemorate Pathos finally hitting Steam:

https://store.steampowered.com/app/5062560/Pathos/

A lot of these are unimplemented as far as I remember,

stylistically they are based on the Nevanda tileset for NetHack so they're based on a 32x32 sprite size

if you wish to use them in your roguelike or in your NetHack tileset, please, do let me know and do give credit.
